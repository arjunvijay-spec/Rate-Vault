💰 RateVault – Smart Currency Converter Web Application

RateVault is a modern multi-page currency converter web app that provides real-time exchange rates, historical data, analytics, and user management using a free public API. Designed with a premium glassmorphism UI and smooth animations for a fintech-style experience.
